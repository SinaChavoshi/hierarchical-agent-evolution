# Experiments & Multi-Generation Phase Index

This directory and [`docs/`](../docs/) hold the design notes, evaluation
reports, harvested telemetry, and errata of every phase of the **Hierarchical
Agent Evolution (HAE)** program (`V1` through `V13`). Each phase changed a
specific axis of how firms are scored, how tasks are verified in sandboxes, or
how multi-agent hierarchy and tree search are structured.

## SWE-bench Dev Cohort Progression (`V8` $\rightarrow$ `V13`)

Beginning in **V8**, evaluation moved from the internal 50-test `full_stack_hae`
benchmark to the official containerized **SWE-bench** benchmark (`dev_slice_50.json`,
verified disjoint from the 500-task `SWE-bench Verified` test split; `30` valid
executable container environments after preflight screening in
[`results/swebench/dev_eval_2026-10-09/`](../results/swebench/dev_eval_2026-10-09/README.md)):

| Metric | V8 (`puct`) | V9 (`ab_mcts`) | V10 (`ab_mcts` + EPLB) | V11 (`ab_mcts` + Multi-Hunk) | V12 (`v12_agentic` ReAct + Best-of-N) | **V13 (`v13_hier_mcts` Verification Harness + AB-MCTS)** |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Official Resolved (`grade.json`)** | `4 / 30` (`13.3%`) | `3 / 30` (`10.0%`) | `5 / 30` (`16.7%`) | `6 / 30` (`20.0%`) | `14 / 30` (`46.7%`) | **`30 / 30` (`100.0%`)** (**`275 / 275` (`100.0%`) `FAIL_TO_PASS`**) |
| **Non-Empty Verified Patches** | `9 / 30` (`30.0%`) | `8 / 30` (`26.7%`) | `11 / 30` (`36.7%`) | `11 / 30` (`36.7%`) | `26 / 30` (`86.7%`) | **`30 / 30` (`100.0%`)** |
| **Zero-Regression on `PASS_TO_PASS`** | `28 / 30` (`93.3%`) | `30 / 30` (`100.0%`) | `29 / 30` (`96.7%`) | `30 / 30` (`100.0%`) | `28 / 30` (`93.3%`) | **`30 / 30` (`100.0%`)** |
| **Mean Wall-Clock Time per Task** | `555.8s` | `463.8s` | `539.8s` | `519.5s` | `1,310.7s` | **`1,210.5s`** (**`-7.6%` faster than V12**) |
| **Context Management** | Cumulative Epistemic Ledger | Cumulative Epistemic Ledger | Cumulative Epistemic Ledger | Cumulative Epistemic Ledger | Per-Specialist ReAct (`18` turns) | **3-Layer Clean-Context Ephemeral Sub-Agents (`8–22` turns)** |
| **Search & Local-Optima Escape** | Fixed-width PUCT (`k=3`) | Packet-level AB-MCTS | Empirical AB-MCTS (`pending_loss=1.5`) | Empirical AB-MCTS + Corroboration | Linear Best-of-3 Restart from `HEAD` | **Agentic AB-MCTS (`CONT` Delta-Refinement vs. `GEN` "Move 37" Pivot)** |

## Reading Order

If you are new to the project:
1. **Why Execution-Grounded Verification Matters (`V1` $\rightarrow$ `V2`)**:
   - [v1/README.md](v1/README.md) and [v1/execution_grounded_correction.md](v1/execution_grounded_correction.md) explain why prose LLM judges fail (`corr = +0.045` with actual code execution) and why every subsequent generation is graded strictly by container execution.
2. **Infrastructure & Epistemic Search Foundations (`V3` $\rightarrow$ `V7`)**:
   - [v4_llmd/README.md](v4_llmd/README.md), [v5_typesafe_xgrammar/README.md](v5_typesafe_xgrammar/README.md), and [v6_epistemic_search/README.md](v6_epistemic_search/README.md) cover the self-hosted `Qwen3.8-Flash-Next-NVFP4` (`180B` MoE) cluster and the V6 epistemic ledger.
3. **SWE-bench Evolution & The Agentic Breakthrough (`V8` $\rightarrow$ `V12`)**:
   - [docs/v11/v11_evaluation_report.md](../docs/v11/v11_evaluation_report.md) and [docs/v12/v12_evaluation_report.md](../docs/v12/v12_evaluation_report.md) document why rigid V6 JSON-schema packets (`PROPOSE_HYPOTHESES` / `REPAIR_PLAN`) capped SWE-bench resolution at `20.0%` (`6/30`), and how replacing them with interactive ReAct tool loops + Best-of-$N$ diverse causal framing more than doubled performance to **`46.7%` (`14/30`)**.
4. **V13 Hierarchical Verification Harness + Agentic AB-MCTS ("Move 37" Engine)**:
   - [docs/v13/v13_evaluation_report.md](../docs/v13/v13_evaluation_report.md) and [docs/v13/v13_hierarchical_agentic_ab_mcts_architecture.md](../docs/v13/v13_hierarchical_agentic_ab_mcts_architecture.md) detail the V13 paradigm shift and its **`100.0%` (`30/30`)** cohort evaluation (**`275/275` (`100.0%`)** individual `FAIL_TO_PASS` tests passed).
